# Tavily Plugin for Grok Build

> [!IMPORTANT]
> **This repository is archived.** The Tavily plugin for Grok Build is now maintained in [tavily-ai/skills](https://github.com/tavily-ai/skills). Please file issues and contributions there.

## Installation

In Grok Build, open `/plugin`, search for **Tavily**, and install it. It adds the Tavily skills and connects Grok to Tavily's hosted MCP server.

For details on the included skills and other supported agents, see the [Grok Build plugin section](https://github.com/tavily-ai/skills#grok-build-plugin) of the tavily-ai/skills README. The plugin manifest is in [`.grok-plugin/`](https://github.com/tavily-ai/skills/tree/main/.grok-plugin).
